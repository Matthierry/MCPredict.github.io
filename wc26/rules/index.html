Rules / FAQs

2026 Game Rules

  1. Deadline: All entries must be submitted and paid for before 11:59pm UK time on Wednesday 10th June 2026.
  2. All predictions of all players will be posted on the website before the first fixture of the 2026 World Cup starts.
  3. Scoring system:
    1. 1 point for a correctly predicted result (1x2 market)
    2. 1 point for a correctly predicted under/over 2.5 goals
    3. 2 points for a correctly predicted score
    4. The maximum number of points a player can score from any match is 4 points.
  4. All three categories will be scored from the one score you predict for each game.
  5. Tie-breakers: If any two positions in the league table are tied at the end of the tournament on overall points, the final positions will be decided on the following priority order:
    1. Correct scores (multiple outcomes)
    2. Correct results (3 possible outcomes)
    3. Correct under/over 2.5 goals (2 possible outcomes)
    4. A tie-breaker question
    5. A secondary tie-breaker using the knockout stage games.
  6. If a fixture is postponed, the original prediction will carry over to when the game takes place.
  7. If a fixture is cancelled, all players will score 0 points for the fixture.
  8. All predictions are based on the group stages of the 2026 World Cup only.
  9. Incorrect predictions: Predictions that are input incorrectly, for example you typed in 2-0 but meant 0-2, will not be fixed regardless of how obvious the error may seem.
